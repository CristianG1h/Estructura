# Estructura

Copia histórica de un sitio basado en WordPress 5.9.3. Incluye el núcleo de WordPress y recursos de la instalación, como temas y complementos en `wp-content/`.

Para estudiar la estructura, revisa `wp-content/themes/` y `wp-content/plugins/`. Para levantar un sitio nuevo, parte de una instalación actual de WordPress en un entorno de pruebas y configura una base de datos de prueba. Mantén la configuración de cada entorno y los respaldos fuera del repositorio.

La documentación original de WordPress está en [readme.html](readme.html) y los términos de licencia en [license.txt](license.txt).
